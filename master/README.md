# Мастер предпродажной подготовки юрлиц

Откройте `master.html` в браузере (Chrome/Edge/Firefox). Установки, сервера и интернета не нужно.

1. Перетащите в окно выгрузки 1С, реестр ЮЛ и реквизиты (или нажмите «Показать на демо-данных»).
2. Если юристы правили шаблоны — кнопка «Шаблоны» → загрузите файлы Word из папки `templates/`.
3. Идите по шагам; на шаге 6 собирается выпуск документов на подпись и ведется дело (статусы, редакции, расхождения).
4. **Сохраняйте файл дела** после каждого выпуска и смены статуса — это память о номерах и подписанном.

Исходники — `src/`, сборка — `python3 build.py`, тесты — `tests/`. Подробно — `src/docs.md` (в приложении кнопка «?»).
