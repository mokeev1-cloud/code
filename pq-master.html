⚙ Мастер PQ

Отладчик, оптимизатор и NDA-шлюз для Power Query — всё локально в браузере
🔒 Офлайн · сеть запрещена CSP книга не загружена

Загрузка

Перетащите сюда .xlsx · .xlsm · .xlsb · .pbix · .pbit или
Читается только M-код (DataMashup) и метаданные запросов. Содержимое листов, кэши сводных и модель данных не читаются.
Как выгрузить из каждого формата — подсказки
  • .xlsx / .xlsm — просто укажите файл книги. Если книга открыта в Excel, сохраните её и лучше закройте (или сохраните копию «Файл → Сохранить копию»). Запросы хранятся внутри книги в части customXml/item*.xml.
  • .xlsb — то же самое: двоичная книга хранит Power Query в той же XML-части. Обратная сборка поддерживается.
  • .pbit (шаблон Power BI) — самый надёжный способ для Power BI: «Файл → Экспорт → Шаблон Power BI». Шаблон не содержит данных модели, только определения.
  • .pbix — читается, если внутри есть часть DataMashup (старый формат). В новом формате (расширенные метаданные) запросы лежат в сжатой модели данных и недоступны — сохраните как .pbit.
  • M-код текстом — редактор Power Query → запрос → «Главная → Расширенный редактор» → Ctrl+A, Ctrl+C → «Вставить M-код текстом». Несколько запросов можно вставить в виде shared Имя = …;. Обратная сборка файла в этом режиме недоступна — на выходе текст для вставки в Расширенный редактор.

    Линтер и оптимизатор

    Эвристики по тексту M-кода: свёртка запросов (query folding), Formula.Firewall, повторные чтения источника, хрупкие шаги, культура и кодировки. Это подсказки, а не вердикт — Power Query решает окончательно только при выполнении.

    Параметризатор

    Захардкоженные пути, серверы, базы и URL выносятся в запросы-параметры. Код становится переносимым, а для ИИ источники уходят из логики запросов в одно место. Изменения попадают в рабочую версию — собрать книгу можно на вкладке «Обратная сборка».

    🤖 Режим агента: Claude Code через папку обмена
    
    
    Claude Code работает только в папке обмена и видит только то, что эта страница сама туда положила: обезличенный код, граф, замечания линтера, обезличенную диагностику, схему и синтетические данные. Ответы (патчи и запросы) он пишет в inbox/. Страница показывает их вам и применяет только после вашего подтверждения. Оригиналы и словарь в папку обмена не попадают никогда — это жёсткое правило кода, а не настройка.
    
    
    Шлюз держится на изоляции. Если Claude Code может прочитать папку с оригиналом книги, он прочитает её и без этой страницы. Поэтому: (1) запускайте Claude Code из папки обмена; (2) держите оригиналы и словарь в другой папке; (3) используйте сгенерированный ниже .claude/settings.json: он запрещает Bash, веб-доступ и чтение папок с оригиналами. Максимальная изоляция — запуск Claude Code под отдельной учётной записью или в контейнере, куда смонтирована только папка обмена.

    Встроенный самотест
    
    
    Создаёт в памяти тестовую книгу .xlsx с запросами: SQL с NativeQuery, папка (UNC), локальный CSV, веб-API с ключом и Bearer-токеном, ODBC с паролем в строке подключения, ссылки между запросами. Затем прогоняет её туда и обратно и сверяет результат с оригиналом побайтно по Section1.m и по остальным частям книги.
