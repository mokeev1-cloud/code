Агент: Claude Code через папку обмена

Claude Code работает только в папке обмена и видит лишь то, что туда положила эта страница: обезличенный код, граф, замечания, обезличенную диагностику, схему и синтетические данные. Ответы (патчи и запросы) он пишет в inbox/, страница показывает их вам и применяет только после подтверждения. Оригиналы и словарь в папку обмена не попадают никогда — это ограничение кода, а не настройка.

Шлюз держится на изоляции. Если Claude Code может прочитать папку с оригиналом, он прочитает её и без этой страницы. Запускайте Claude Code из папки обмена, держите оригиналы и словари в другой папке и используйте сгенерированный ниже .claude/settings.json. Лучшая изоляция — отдельная учётная запись или контейнер, где смонтирована только папка обмена.
