Проверка на данных

🔒 Данные читаются и обрабатываются только в этом браузере — сеть запрещена. Наружу (пакет для ИИ, папка обмена) уходят только числа проверок, без значений; если в исходящем тексте окажется значение из данных, сканер заблокирует выпуск.
