Мастер PQ

Редактор, оптимизатор и NDA-шлюз для Power Query. Работает целиком в браузере: книга не покидает компьютер, сетевые запросы запрещены.

Перетащите сюда книгу — .xlsx · .xlsm · .xlsb · .pbix · .pbit
Читается только M-код и метаданные запросов. Содержимое листов и модель данных не читаются.

M-код текстом

из «Расширенного редактора» или section Section1; с несколькими shared
Как выгрузить из каждого формата
  • .xlsx / .xlsm / .xlsb — укажите файл книги. Чтобы потом сохранить «в оригинал», закройте книгу в Excel (Windows блокирует открытые файлы).
  • .pbit — самый надёжный путь для Power BI: «Файл → Экспорт → Шаблон Power BI».
  • .pbix — читается, если внутри есть часть DataMashup (старый формат). Новый формат хранит запросы в сжатой модели — сохраните как .pbit.
  • M-код текстом — редактор Power Query → запрос → «Расширенный редактор» → Ctrl+A, Ctrl+C.

Недавние файлы

Что здесь есть

  • Редактор M с подсветкой, автодополнением, подсказками сигнатур и справкой по функциям
  • Оптимизатор: находит проблемы, показывает карту тяжести шагов и сам исправляет книгу
  • Песочница: вычисление M и пошаговый прогон запроса на образце данных
  • NDA-шлюз: обезличивание кода и диагностики для ИИ, обратная подстановка
  • Сниппеты, рефакторинг, история с откатом, документация книги
Нажмите Ctrl+K в любой момент — палитра команд.
