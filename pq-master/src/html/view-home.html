Мастер PQ

Ускоритель и редактор кода Power Query. Показывает, где книга теряет время, сам исправляет то, что можно доказать на ваших данных, и помогает дорабатывать — вручную или вместе с ИИ через обезличенный обмен.

Перетащите сюда книгу — .xlsx · .xlsm · .xlsb · .pbix · .pbit
Всё — только в этом браузере, сеть запрещена. Таблицы книги и прикреплённые выгрузки читаются локально — для проверки запросов на данных. Наружу (ИИ, папка обмена) уходит только обезличенное.

M-код текстом

из «Расширенного редактора» или section Section1; с несколькими shared
Как выгрузить из каждого формата
  • .xlsx / .xlsm / .xlsb — укажите файл книги. Чтобы потом сохранить «в оригинал», закройте книгу в Excel (Windows блокирует открытые файлы).
  • .pbit — самый надёжный путь для Power BI: «Файл → Экспорт → Шаблон Power BI».
  • .pbix — читается, если внутри есть часть DataMashup (старый формат). Новый формат хранит запросы в сжатой модели — сохраните как .pbit.
  • M-код текстом — редактор Power Query → запрос → «Расширенный редактор» → Ctrl+A, Ctrl+C.

Недавние файлы

Что здесь есть

  • Карта модели — источники, запросы, объёмы и время с одного взгляда
  • Проверка на данных — запросы вычисляются на таблицах книги и выгрузках: дубли ключей, потери строк и сумм
  • ⚡ Ускорить книгу — проверенные исправления кода и настроек одной кнопкой и отчёт «было → стало»
  • Редактор M — подсказки, проблемы в коде и живые данные шага под курсором
  • Обмен с ИИ — обезличенный пакет, проверка глазами, ответ сверяется на данных до принятия
  • Запись в книгу — копия или в оригинал с резервной копией; история правок с откатом
Нажмите Ctrl+K в любой момент — палитра команд.
