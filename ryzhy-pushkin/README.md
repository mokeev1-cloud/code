# Рыжий и Пушкин — прямые параллели

## Корпус
- `corpus/pushkin/` — А. С. Пушкин, Собрание сочинений в 10 т. (М.: ГИХЛ, 1959–1962), источник rvb.ru.
  `html/` — 2032 исходные страницы, `pushkin_10vol.txt` — сводный текст (2009 текстов, порядок оглавлений томов).
  Перекачать: `python3 tools/fetch_pushkin.py corpus/pushkin/html && python3 tools/rvb_to_txt.py corpus/pushkin/html corpus/pushkin/pushkin_10vol.txt`.
- `corpus/ryzhy/` — Б. Рыжий, **не в git** (авторское право; репозиторий публичный). Восстановить: `tools/fetch_ryzhy.sh`.
  - «В кварталах дальних и печальных» (2012), fb2 → 536 стихотворений;
  - «Оправдание жизни» (Екатеринбург, 2015) — лирика, ранние, проза, критика, интервью, письма (djvu → OCR-текст);
  - «На холодном ветру», «И всё такое…» (pdf → текст).
  Полного академического собрания у Рыжего нет; «Оправдание жизни» — самое полное из доступных.
