# Рыжий и Пушкин — прямые параллели

Рабочий проект: поиск прямых перекличек Бориса Рыжего (1974–2001) с
Пушкиным (и с посредниками: Державин, Блок, Есенин, Гандлевский).

## Что где лежит

```
ryzhy-pushkin/
├── README.md                     — этот файл
├── 01_dalnyh-i-pechalnyh.md      — ОТЧЁТ по задаче 1: троп «дальный — печальный»
│                                   (разделы 1–14: Пушкин, «Море» Рыжего, Державин,
│                                   Блок, Есенин, Гандлевский, море = смерть / контрчтение,
│                                   болдинская триада, акустическая проверка записи)
├── corpus/
│   ├── pushkin/
│   │   ├── pushkin_10vol.txt     — Пушкин, Собр. соч. в 10 т. (ГИХЛ, 1959–62), все тома,
│   │   │                           2009 текстов, один файл UTF-8 (общественное достояние)
│   │   └── html/                 — исходные страницы rvb.ru (не в git и не в архиве;
│   │                               восстанавливаются fetch_pushkin.py)
│   └── ryzhy/                    — Рыжий (АВТОРСКОЕ ПРАВО: не в git, только для личной работы)
│       ├── ryzhy_v-kvartalah-2012.txt   — «В кварталах дальних и печальных» (2012), 536 стих.
│       ├── ryzhy_opravdanie-zhizni.txt  — «Оправдание жизни» (2015): лирика, ранние, проза,
│       │                                  критика, интервью, письма, воспоминания (OCR!)
│       ├── ryzhy_i-vse-takoe.txt        — «И всё такое…» (СПб., 2000) — прижизненное
│       ├── ryzhy_na-holodnom-vetru.txt  — «На холодном ветру»
│       └── raw/                         — исходные fb2 / pdf / djvu
├── audio_check/                  — проверка записи авторского чтения «Моря»
│   ├── spectrogram.png           — спектрограммы обеих строк с «дальн?х»
│   └── dalnyh_*.mp3              — фрагменты записи (обычные и замедленные 0.6×; не в git)
└── tools/                        — скрипты (все откомментированы, см. шапку каждого)
    ├── fetch_pushkin.py          — скачать 10-томник с rvb.ru
    ├── rvb_to_txt.py             — собрать pushkin_10vol.txt из скачанных страниц
    ├── fetch_ryzhy.sh            — скачать и сконвертировать 4 издания Рыжего
    ├── fb2_to_txt.py             — FB2 -> текст (используется fetch_ryzhy.sh)
    ├── trope_dalny.py            — поиск «дальн-/далёк- рядом с печальн-», пометка рифм
    ├── dalny_forms.py            — подсчёт твёрдых (дальный) и мягких (дальний) форм
    └── audio/
        ├── asr.py                — Whisper: расшифровка записи с таймкодами
        ├── spec.py               — спектрограмма с формантами
        └── phon3.py              — фонемный распознаватель: мягкое или твёрдое «н»
```

## Как воспроизвести

```bash
cd ryzhy-pushkin
# Пушкин
python3 tools/fetch_pushkin.py corpus/pushkin/html
python3 tools/rvb_to_txt.py corpus/pushkin/html corpus/pushkin/pushkin_10vol.txt
# Рыжий (нужны poppler-utils и djvulibre-bin)
tools/fetch_ryzhy.sh
# Задача 1
python3 tools/dalny_forms.py corpus/pushkin/pushkin_10vol.txt corpus/ryzhy/*.txt
python3 tools/trope_dalny.py corpus/pushkin/pushkin_10vol.txt corpus/ryzhy/*.txt
# Запись (зависимости — в шапках скриптов)
ffmpeg -i запись.mp3 -ac 1 -ar 16000 ryzhy.wav
python3 tools/audio/asr.py ryzhy.wav large-v3
python3 tools/audio/spec.py ryzhy.wav audio_check/spectrogram.png
python3 tools/audio/phon3.py ryzhy.wav
```

## Оговорки по источникам
- Полного академического собрания Рыжего нет; «Оправдание жизни» — самое полное
  из доступных, но его текст получен OCR (возможны опечатки).
- В 10-томнике Пушкина нет черновиков и вариантов (они есть в Большом академическом
  16-томнике) — для полноты по черновикам нужен 16-томник.
- Блок, Есенин, Державин, Гандлевский в корпус пока не загружены: их тексты в
  отчёте сверены по ru.wikisource (Блок, Державин) или процитированы по памяти
  (Есенин) / присланы пользователем (Гандлевский) — это указано в отчёте.
- Принадлежность голоса на записи (20_ryzhiy1.mp3) самому Рыжему не проверена.
